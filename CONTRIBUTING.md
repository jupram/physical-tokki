# Contributing to Physical Tokki

Thank you for contributing. The default branch is `main` and is protected.
Contributors must propose changes through a pull request; do not push directly
to `main`.

## Workflow

1. Fork the repository or create a feature branch if you have collaborator access.
2. Branch from the latest `main` using a short, descriptive branch name.
3. Keep each change focused and follow the existing project structure.
4. Run the relevant firmware or desktop checks described in the
   [README](README.md).
5. Open a pull request against `jupram/physical-tokki:main`.
6. Address review feedback and wait for the required owner approval before merge.

Force pushes and deletion of `main` are not permitted. Repository administrators
retain an emergency bypass for maintenance and direct owner updates.
